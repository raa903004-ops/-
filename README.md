# 🌸 Blush Day — розовый планер

Красивый адаптивный планер на русском языке.

## Возможности
- Задачи и чек-листы для каждой даты
- Календарь с выбором дня
- Трекер привычек: вода, чтение, забота о себе, сон
- Заметки на каждый день
- Прогресс выполнения задач
- Автоматическое сохранение через localStorage

## Запуск
Откройте `index.html` в браузере. Никакая сборка не нужна.

## GitHub Pages
Откройте **Settings → Pages → Build and deployment → Deploy from a branch** и укажите ветку `blush-day-planner` и папку `/(root)`.

**Важно:** записи хранятся локально в том браузере, где их создают. Между устройствами они не синхронизируются. Очистка данных сайта удалит записи.
