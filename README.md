# 🌸 Mina Planner

Русскоязычная персональная учебная система: задачи, календарь, олимпиады, курсы, проекты, конспекты, цели, таймер, статистика и отчёты.

## Проверяемые этапы

| Этап | Ветка | Что добавлено |
| --- | --- | --- |
| 1 | [mina-stage-1-core](../../tree/mina-stage-1-core) | Учебные сущности, создание, изменение и хранение записей |
| 2 | [mina-stage-2-dashboard](../../tree/mina-stage-2-dashboard) | Главная панель, визуальное оформление, демонстрационные записи |
| 3 | [mina-stage-3-reports](../../tree/mina-stage-3-reports) | Учебный таймер, аналитика, отчёты за неделю, CSV |
| 4 | [mina-stage-4-smart-planning](../../tree/mina-stage-4-smart-planning) | Анализ учебной нагрузки и рекомендации на основе правил |
| 5 | [mina-stage-5-integrations](../../tree/mina-stage-5-integrations) | Экспорт .ics, ссылка через Telegram, уведомления пока открыт сайт |

Ветка `blush-day-planner` содержит последнюю версию и используется для GitHub Pages.

## Как запускать каждый этап

Открой нужную ветку в GitHub, скачай ZIP через Code → Download ZIP и открой `index.html` в браузере. Ветка `blush-day-planner` дополнительно публикуется на GitHub Pages.

## Данные

Всё хранится в `localStorage` текущего браузера. Для переноса между устройствами используй **Настройки → Экспорт JSON / Импорт JSON**. Автоматической облачной синхронизации пока нет.

Демонстрационные записи можно удалить на главной странице кнопкой «Очистить пример». Это не настоящие даты и не официальные сведения об олимпиадах.

## Интеграции и ограничения

- **Google Calendar:** скачивание .ics для ручного импорта. Это **не двусторонняя синхронизация** и не OAuth-интеграция.
- **Telegram:** отправка ссылки через экран «Поделиться в Telegram». **Telegram-бот не подключён**.
- **Уведомления:** разрешаемые браузерные уведомления о сроках при открытой странице, проверка примерно раз в минуту; **фоновых Web Push при закрытом сайте нет**.
- **Умный помощник:** локальные алгоритмы оценки нагрузки и советов; **не генеративная ИИ-модель**.
- **Таймер:** работает во вкладке. Статистика фокуса записывается локально.
- Для реального ИИ, Telegram-бота, синхронизации с Google Calendar и Web Push понадобится backend, авторизация и соответствующие API.
