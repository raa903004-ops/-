# ✦ Mina Planner

Русскоязычный персональный учебный центр для планирования школы, олимпиад, курсов, исследований и поступления в университет.

## Что реализовано

- **Главная панель:** метрики, дела дня, ближайшие дедлайны, олимпиады, неделя; порядок виджетов можно менять перетаскиванием.
- **Задачи:** категории, приоритеты, время, дата выполнения, дедлайн, напоминание, выполнение, редактирование, удаление, сортировка перетаскиванием.
- **Календарь:** просмотр по месяцам, неделя, разовые и еженедельные события с временем и цветовой кодировкой.
- **Олимпиады:** организатор, предмет, уровень, год, место, формат, даты регистрации, этапы, ссылки на задания и разборы, требования, заметки и результат; кнопка создания задачи подготовки.
- **Курсы, научные проекты, база знаний и образовательные цели:** создание, редактирование, удаление и поля прогресса.
- **Фокус:** Pomodoro 25 минут, учёт учебного времени.
- **Аналитика:** прогресс, категории задач, недельная статистика.
- **Быстрый ввод:** локальное распознавание даты на русском, категории и напоминания; перед сохранением открывается форма проверки.
- **Настройки:** тёмная тема, акцентный цвет, экспорт и импорт резервной копии JSON.
- **Локальные напоминания:** проверка ближайших сроков в разделе уведомлений, разрешаемые уведомления о завершении таймера.

## Запуск

Откройте `index.html` в браузере или опубликуйте GitHub Pages из ветки `blush-day-planner`, папка `/(root)`.

## Ограничения и хранение

**Это клиентское приложение без сервера и аккаунтов.** Данные сохраняются через `localStorage` в текущем браузере и не синхронизируются автоматически между устройствами. Для переноса служат кнопки «Экспорт JSON» и «Импорт JSON» в настройках. Очистка данных сайта удалит локальную базу.

«Умный» ввод — правила разбора текста, **не подключение к модели ИИ**. Фоновые push-уведомления и постоянные напоминания при закрытом браузере не работают. Таймер также работает только при открытой вкладке.

Приложение не содержит автоматического внешнего каталога олимпиад: базу олимпиад пользователь заполняет самостоятельно.

## Технологии
